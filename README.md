### macOS tools I ship

**[Corta](https://github.com/noah-qin/Corta)** — a native macOS terminal: Metal rendering, first-class CJK / IME input, dependency-free VT core.  
[Download](https://github.com/noah-qin/Corta/releases/latest) · macOS 26+
